## 🚀 Quick Start Guide

Run the full experience locally in **seconds**:

```bash
# 1. Clone the repository
git clone https://github.com/Abhimanyuraj8252/QUANTUM-TOOLS.git

# 2. Enter directory
cd QUANTUM-TOOLS

# 3. Start local server (Python 3)
python -m http.server 8000

# 4. Open in browser
# Visit http://localhost:8000
```
